# Installation

## ⚡ From PyPI (recommended)

```bash
pip install drexpa
```

## 🛠️ Development installation

```bash
git clone https://github.com/druglogics/drexpa.git
cd drexpa
pip install -e ".[dev]"
pytest  # Validate installation
```

## 📋 Requirements

Dependencies: `Python 3.8+`, `pandas`, `numpy`, `chembl_webresource_client`.

## 🔗 Source code

The source code is available at [github.com/druglogics/drexpa](https://github.com/druglogics/drexpa).
